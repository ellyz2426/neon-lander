# Neon Lander VR — Round 2 Journal

## Session: 1am sentinel check-in continuation
## Time: ~10 minutes

### Work Done
1. **Critical input fix**: Changed `getKeyDown` → `getKeyPressed` for thrust (W/Up/Space) and rotation (A/D/Left/Right). The old code only registered input for a single frame, making the game essentially unplayable.

2. **Camera tracking**: Added smooth camera follow on lander position. Camera offset tracks lander XY with 0.3 strength factor and exponential smoothing (CAM_SMOOTH=3.0).

3. **Crash screen shake**: 0.4 second decaying random shake on camera when lander crashes. Detects state transition to CRASHED.

4. **HUD improvements**:
   - Fuel bar: green→yellow→red color transitions based on fuel percentage
   - Velocity danger colors: VX/VY text changes green/yellow/red based on safe landing thresholds
   - Angle danger color: same pattern for tilt angle
   - Status indicator: "SAFE" / "CAUTION" / "DANGER" with matching colors
   - Countdown display: shows "3... 2... 1..." during READY state
   - Replaced ♥ glyph (missing font) with "HP" text

5. **Wind indicator**: ConeGeometry arrow mesh near lander showing wind direction, scaled by wind strength.

6. **Landing dust particles**: 12-particle burst on successful landing with radial spread.

7. **Code quality**: Removed requestAnimationFrame pad glow loop, moved to GameSystem ECS update.
